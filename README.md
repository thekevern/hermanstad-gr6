# Graad 6 Eksamen-Oorlewingsgids (Laerskool Hermanstad)
**November-Eksamen 2026 • Slim Studieplan & Eksamen-Afrigter**

'n Mobiel-vriendelike, vanlyn-gereed Progressive Web App (PWA) vir eksamenvoorbereiding in Afrikaans.

### Funksionaliteit:
- **107 Leitner 3-Boksie Flitskaarte:** Aktiewe herroeping met afbakening van al 8 eksamenvraestelle.
- **70 Diagnostiese Meerkeusevrae:** Retrieval practice met onmiddellike verduidelikings en bladsyverwysings.
- **Slim Swakplek-Afrigter:** Identifiseer swakste sub-vaardighede en bou outomatiese teikenoefeninge.
- **Pomodoro 25m/5m Timer:** Fokus- en pouse-afrigter met Web Audio klankseine.
- **15:30 Outomatiese Studie-Alarm:** Weeksdae stootkennisgewing.
- **WhatsApp-Sinkronisasie met Pa (+27 68 600 0549):** Stuur regstreekse vorderingsverslae.
- **Gereed vir Render.com en GitHub Pages:** Statiese webblad-gasheerskap via HTTPS.
